## 截图处理

- 四张手机原图均为 1179 × 2556 像素，保留区域为 `(left=0, top=310, right=1179, bottom=2510)`。顶部状态栏与完整地址栏被裁去，域名不再出现在成品中；底部同时去掉少量边缘内容。
- 手机截图等比缩放至宽 780 像素（高度四舍五入为 1455），桌面截图由 2898 × 1446 缩放为 2048 × 1022。
- 使用 Pillow 的 Lanczos 重采样与 PNG 无损编码，重新创建像素图后保存，剥离原图元数据。
- 页面内容、数据与操作状态保持原样，没有用模拟数据替换或拼接页面元素。图片尺寸是成品像素尺寸，不代表浏览器 CSS 视口。
- README 将手机图按「首页 / 食物库」与「库存 / AI 助手」两组排列，点击可查看处理后的大图。

更换页面截图时，先在仓库外完成裁切和域名处理，逐张检查后再替换这里的 PNG。不要将原始图片、浏览器地址栏或私有访问链接放进仓库，也不要覆盖 E2E 截图基线。

## 重新生成封面

封面由 `banner.html` 渲染，复用仓库已有 `frontend/public/icon-192.png` 与 `frontend/public/images/family-kitchen-cover.jpg`，不依赖外链图床。

安装前端依赖和 Playwright Chromium 后，从仓库根目录运行：

```bash
node docs/screenshots/render-banner.mjs
git diff --check
```

此命令只更新 `banner.png`，不会改动用户提供的页面截图，也不需要启动前后端服务。
